# Build outputs

Download `ew30sx-<tag>-nor` or `ew30sx-<tag>-ram` from the repository's
Actions tab, or get the optional prerelease archives. GitHub Pages carries
the three most recent published builds; archive the matching APK feed if
you need it after the build ages out of Pages.
Each layout (`nor`, `ram`) has its own firmware, build metadata, signed APK
indexes and public key. Keep them paired with the exact run and attempt.
Firmware and package binaries are not tracked on the source branch.
Signing private keys are never published.
